# layeredInterface1D

Time-domain heterogeneous/interface validation case for `acousticWaveFoam`.

## What This Case Checks

- Normal-incidence acoustic reflection/transmission at a planar material interface.
- Material jump is represented with `alpha.water`:
  - `alpha.water = 0`: gas-side medium (`rhog`, `cg`)
  - `alpha.water = 1`: liquid-side medium (`rhol`, `cl`)
- A right-end rectangular PML damps the transmitted wave.
- Probe output records pressure time histories on both sides of the interface.

## Run

```bash
./Allrun
```

The default run is serial. This avoids an OpenFOAM `reconstructPar` issue with
the time-dependent `uniformFixedGradient` pressure boundary.

For quick smoke tests, override parameters from the shell:

```bash
NX=400 N_PERIODS=1 STEPS_PER_PERIOD=50 ./Allrun
```

## Key Files

- `caseParams.sh`: drive frequency, media, interface position, PML, mesh, and time controls.
- `0.orig/p.in`: time-harmonic pressure-gradient driver at the left boundary.
- `system/controlDict.in`: generated by `prepareCase`.
- `postProcessing/lineProbes/0/p`: pressure time histories.

## Analytical Reference

For normal incidence, compare reflected/transmitted amplitudes with:

```text
R = (Z2 - Z1)/(Z2 + Z1)
T = 2*Z2/(Z2 + Z1)
Z = rho*c
```
