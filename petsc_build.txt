PETSc setup guide for TwoPhaseFlow
=================================

This project is currently configured to use PETSc from:
  $HOME/petsc
with
  PETSC_ARCH=arch-linux-c-opt

The steps below explain how a new user can prepare PETSc and verify the solver build.

1) Prerequisites
----------------
Install a C/C++ compiler, MPI and basic build tools (example on Ubuntu):

  sudo apt update
  sudo apt install -y build-essential cmake gfortran openmpi-bin libopenmpi-dev python3

2) Get PETSc source
-------------------
Choose a location (example keeps current layout):

  cd $HOME
  git clone -b release https://gitlab.com/petsc/petsc.git petsc
  cd petsc

(Optional) checkout a specific version if needed by your workflow.

3) Configure PETSc
------------------
The following is a good default for this repository (double precision, optimized build):

  ./configure \
    --with-debugging=0 \
    --with-precision=double \
    --with-64-bit-indices=0 \
    --COPTFLAGS=-O3 --CXXOPTFLAGS=-O3 --FOPTFLAGS=-O3 \
    --with-mpi=1 \
    --download-f2cblaslapack

If you want stronger Helmholtz solver options, configure with extra packages:

  ./configure \
    --with-debugging=0 \
    --with-precision=double \
    --with-64-bit-indices=0 \
    --COPTFLAGS=-O3 --CXXOPTFLAGS=-O3 --FOPTFLAGS=-O3 \
    --with-mpi=1 \
    --download-f2cblaslapack \
    --download-hypre \
    --download-mumps \
    --download-superlu_dist \
    --download-scalapack

4) Build PETSc
--------------

  make all

(If configure printed a specific -j recommendation, use it.)

5) Environment variables
------------------------
For this project, use:

  export PETSC_DIR=$HOME/petsc
  export PETSC_ARCH=arch-linux-c-opt
  export LD_LIBRARY_PATH=$PETSC_DIR/$PETSC_ARCH/lib:$LD_LIBRARY_PATH

The repository script already sets these:
  TwoPhaseFlow/scripts/bashrc


6) Verify PETSc linkage
-----------------------
Expected include/link paths in build output should reference:
  $PETSC_DIR/include
  $PETSC_DIR/$PETSC_ARCH/include
  $PETSC_DIR/$PETSC_ARCH/lib

Quick checks:

  echo "$PETSC_DIR"
  echo "$PETSC_ARCH"
  ls $PETSC_DIR/$PETSC_ARCH/lib/libpetsc.so

If build fails with "cannot find -lpetsc" or "petscksp.h: No such file":
- Verify PETSC_DIR/PETSC_ARCH are correct.
- Verify $PETSC_DIR/$PETSC_ARCH/lib exists.
- Re-source both bashrc files before wmake.

7) Build petsc4Foam (optional, for fvSolution solver=petsc)
-----------------------------------------------------------
If your case uses `solver petsc;` in `fvSolution`, build petsc4Foam:

  cd /path/to/TwoPhaseFlow
  source ~/TwoPhaseFlow/scripts/bashrc
  source ~/openfoam/etc/bashrc
  cd external/petsc4Foam
  ./Allwmake

This installs `libpetscFoam.so` into the OpenFOAM user/module lib path.

8) Verify petsc4Foam
--------------------
Quick checks:

  foamListBin | rg petscFoam || true
  find "$FOAM_USER_LIBBIN" "$FOAM_LIBBIN" -maxdepth 1 -name 'libpetscFoam.so' 2>/dev/null

For runtime usage in a case, ensure:
- `system/controlDict` has the library loaded, for example:

    libs
    (
        "libpetscFoam.so"
    );

- `system/fvSolution` uses PETSc solver entries, for example:

    solvers
    {
        "P.*"
        {
            solver  petsc;
            petsc
            {
                options
                {
                    ksp_type fgmres;
                    pc_type  gamg;
                }
            }
        }
    }
